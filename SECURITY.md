# Security Policy

## Reporting a vulnerability

Do not report security issues in normal issue threads or release comments.

For the current private alpha, report vulnerabilities privately to the repo
owner:

- Email: `cursivecrow@outlook.com`
- Or open a private GitHub security advisory if that feature is enabled for the
  repository

Include:

- affected commit or release tag
- reproduction steps
- impact assessment
- any suggested mitigation or patch direction

## Response expectations

- Initial acknowledgement target: 3 business days
- Triage/update target: 7 business days
- Fix timing depends on alpha severity and release cadence

The private alpha release process should favor fixing high-severity issues
before publishing a prerelease from the affected branch or tag.
