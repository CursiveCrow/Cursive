# Validate Prewrite Hook Harness

## Objective

Validate that the restarted prewrite hook harness gates writes before implementation
work, accepts a current typed plan artifact, and passes its source and installed
regression suites while formalizing the plan schema and compact injection system.
This is a hook task only; no Cursive compiler behavior is being changed.

## Success Criteria

- The live PreToolUse hook blocks writes before a current typed plan exists.
- The plan document uses formal, parseable top-level sections before Action Items.
- Completed action items use Completion notes.
- The hook injects compact parsed plan context, previous completion notes, and the
  current action item instead of the full plan file.
- Source and installed hook regression suites pass.
